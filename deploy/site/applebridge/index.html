Apple Bridge reads private data. Local use sends nothing off your Mac, but an agent you connect may send what it reads to its own service. Remote access is optional. Review your agent’s settings before connecting.

A few things to know.

Which agents can connect?

Any MCP agent on your Mac. bridge link sets up Claude Code, Codex, Cursor, VS Code, Zed, Gemini CLI, Goose, OpenCode and Claude Desktop in one line, and bridge link other prints the settings for anything else. Grok Bot runs its custom connectors on its own cloud computer, so it cannot reach Apple Bridge on your Mac.

What can it access?

Sources include Messages, Mail, Calendar, Reminders, Contacts and Notes, with additional integrations documented in the repository. Access depends on the permissions you allow. Some sources have limits; Photos native qualification is pending and the iPhone app is in internal testing.

Is this ready for everyone?

This is early-access software. Check known limits before relying on a workflow. You need an Apple silicon Mac running macOS 26 or later.

Can I run it myself?

Yes. Apple Bridge is MIT-licensed open source. Local use needs no hosted service. Source builds and optional remote access are documented in the repository.
