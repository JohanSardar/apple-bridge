# Screen Time from Biome App.InFocus, read-only estimates

The ScreenTimeAgent stores are vaulted even with Full Disk Access and SIP on, so Usage is built from Biome App.InFocus focus transitions (local and synced remote devices) with lock/sleep clipping, published as per-app per-device per-day estimates with provenance. Parity with the Screen Time settings screen is not claimed.
