# Agent operation names are app.verb_object, listed in the tool schema

Agents guessed operation names and lost turns: `reminders.items`, `usage.summary` and `records.query` gave no hint of what they did, `.list` meant different things in different apps, and notes and mail had no search. Over MCP every operation now has one name of the form `app.verb_object`, and `apple_read` and `apple_change` list every name the agent may run as an `enum` on `operation`. Lists end in `.list` (`reminders.list`, `calendar.list`, `messages.list`), searches in `.search`, and operations about Apple Bridge itself share the `bridge.` prefix (`bridge.search`, `bridge.list_records`, `bridge.get_record`). `usage` became `screentime`, and `notes.search`, `notes.get` and `mail.search` are new frontdoor reads over the existing search and record reads.

The old names were removed outright, with no aliases. An old or guessed name never runs. It returns `unknown operation` with `did_you_mean`, an example call and, for an old name, "X was renamed to Y". Suggestions come from the rename table, then from a normalized match that ignores word order, plurals and common synonyms (`get_reminders`, `screen_time.summary`), then from edit distance and the word search behind `apple_describe`. An unknown tool name gets the same suggestions. Because a variant never executes, a guess cannot reach a change that the agent did not name exactly, and changes still wait for the owner's Allow.

The new names exist only in the frontdoor. The catalog, REST `/v1/op/<name>`, OpenAPI, the CLI's `bridge call` and the Helper and iPhone wire keep their catalog names, so installed Helpers and the iPhone app keep working and `catalog.json` does not change. The rename table in `ab-frontdoor/src/mcp_names.rs` is the one place that maps them. The unlisted per-operation MCP tools (`records_query` and the rest, frozen in `mcp-legacy-tools.json`) were removed with the golden, and lab adapters that called them call REST instead.

`apple_describe` with no arguments and `apple_guide` with no name return a short overview: the naming rule and each domain's purpose and operation names. Describing a domain or a query returns each operation's one-line summary, an argument signature such as `text: string, limit?: integer` and an example call. Per-action tools were not added: one tool per operation cost about 33,000 tokens, and the enum gives the same first-try naming within the budget. Listing the tools and instructions measures 5,981 tokens by the budget test's rule (5,638 with o200k), down from 5,996, after trimming tool output schemas to plain objects and shortening descriptions that repeated the instructions.

## Considered options

- Keep the old names as unlisted aliases. Rejected by the owner: two names per operation keeps the guessing alive, and the hint covers the migration.
- Rename the catalog itself. Rejected because the Helper and iPhone wire and REST clients depend on catalog names, and the agent-facing name is a presentation concern of the frontdoor.
