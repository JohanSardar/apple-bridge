The gzip fixtures contain synthetic, tagged Notes protobuf data, not copies of a user's database. `full.json` is the independent expected text, block order and table cell order for `full.gz` plus `full-table.gz`. The table serializes its column and cell dictionaries out of display order to exercise ordered-set reconstruction.

The full fixture covers heading hierarchy, monostyled text, all three list styles, both checklist states and distinct checklist identities, quotes, inline emphasis, a link, highlighting and attachment references. The malformed fixtures cover a split UTF-16 surrogate, duplicate text fields and an incorrect wire type; unknown paragraph styles remain explicit read-only placeholders. Existing small fixtures retain legacy decode coverage.

Field numbers follow the public [Notes schema](https://github.com/threeplanetssoftware/apple_cloud_notes_parser/blob/master/proto/notestore.proto). Decoder and SQLite projection checks run in `NotesDecoderChecks`; AppleTruth counts use a separate parser and do not call the production decoder. Native format coverage is qualified at the Notes milestone.

`native-plain.gz` models a plain Notes.app HTML import with CRDT/replica metadata, LTR writing direction, paragraph UUIDs and a run timestamp. Its first line is the note name but has no explicit Title paragraph style, so it contributes zero title blocks. `split-title.gz` splits an explicit Title paragraph across runs, including a timestamp-only continuation. `native-rich.gz` adds bold formatting to the same native metadata; it must remain read-only. All bytes and identifiers are synthetic.

Native metadata field roles also follow the [expanded schema](https://github.com/shareup/nanotes/blob/main/notestore.proto): Note fields 3/4 hold character CRDT history and replica metadata, AttributeRun field 13 is a timestamp, and ParagraphStyle field 9 is a UUID. Notes.app regenerates sync metadata through the public AppleScript write path; the bridge does not serialize it. ParagraphStyle field 3 value 1 is the observed LTR direction; other values remain read-only until the block contract represents them. Unknown formatting still blocks editing.

`title-attachment.gz` has an explicit Title paragraph whose only content is an inline attachment. The projection retains the Title block and attachment reference: changing its block type to `attachment` would incorrectly remove a schema title from the structure count. Non-table styled paragraphs retain their styles when their content is an attachment.

`native-direction.gz` and `native-unknown.gz` retain the native plain metadata but add an unrepresented writing direction or an unknown paragraph attribute. Both stay rich/read-only, covering the boundary of the metadata allowlist.
