# Focus status and DND writes (T62, partial)

`focus.set` accepts `mode: "Do Not Disturb"`, an explicit boolean `on`, and an optional future RFC3339 `until` when enabling. Agents at both approve and full levels await owner approval. Named Focus writes remain unavailable because INFocusStatusCenter cannot identify the active mode. Status capture preserves unknown values and never requests authorization.

`packaging/shortcuts/ab-focus.json` compiles to AB Focus with the repository shortcut builder. Set Focus's identifier and native parameter definitions were inspected through WorkflowKit without execution; provenance is in `focus-actions.verified.txt`. Import the signed `.build/shortcuts/AB Focus.shortcut` on the test machine before qualification. The pack defaults to DND and selects a timed assertion when an expiry is supplied.

The native FocusSource runs the pack using the bounded Shortcuts runner and independently polls the existing INFocusStatusCenter status for up to four seconds. CLI completion alone cannot establish success. Gateway outcome validation binds the authorized status and requested boolean to the request hash. The Go pack exposes the same injected runner/readback seam for simulation.

FOC-SIM proves pack compilation, injected set/readback/restore, bounded execution, unknown-status refusal, native dispatch, and public gateway approval for both agent levels. FOC-SET-REAL first reads status without requesting a grant. It only toggles when Focus was known inactive, enables DND for one minute, then restores the captured inactive state immediately. Restoration also runs after dispatch/readback failure, using the previously prepared off request even if authorization or status becomes unavailable; independent restoration readback is still attempted and a missing confirmation fails the test. An active or unknown prior Focus results in limited evidence without effects, since its mode and expiry cannot be restored from the current API. FOC-STATUS-REAL uses the same read-only probe. No personal status values enter evidence.

Real qualification needs a Focus status grant and AB Focus import. The standalone native probe must have an existing grant in its execution context; it never requests one. Idle CPU and phone synchronization qualifications remain separate.
