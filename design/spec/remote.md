# Remote onboarding

Embedded tsnet is the default. The private state-file control remains shared between Runtime and CLI. `tailscale-app` selects the existing system backend; `system` remains an alias. No automatic system discovery occurs in embedded mode.

The LocalClient interface supplies status and QueryFeature. Runtime publishes login_pending, funnel_pending, probing, then on. CLI receives approval links only over a private request-scoped Unix socket, prints and opens each distinct link once; browser launch failure leaves a manual link. Status persists fixed pending descriptions, never approval URLs, feature response text or client error bodies. Embedded library logging is disabled. Funnel rechecks every five seconds. Ctrl-C or a disconnected waiting CLI cancels the matching Runtime request, closes its node, HTTP server, active streams and listener, and disables only that request under a config lock. A newer request is preserved. Restarting an abandoned pending request fails closed; ready configurations remain restartable. Embedded off never contacts system tailscaled.

Readiness resolves the hostname using public DNS (1.1.1.1), pins a public IPv4 address excluding private, loopback and Tailscale CGNAT ranges, bypasses proxy environment settings, preserves TLS SNI and requires a trusted certificate. This exercises the public relay from the Mac rather than the tailnet route. It checks OAuth discovery 200, unauthenticated MCP 401 with WWW-Authenticate, app 200 and a 60 second SSE stream. The bounded public `/.well-known/apple-bridge-remote-check` endpoint emits only synthetic comments, once per second, for at most 75 seconds. Failure records last_error and closes serving; rerun on to retry. Certificate expiry is the served certificate NotAfter observed by the probe, refreshed on each on/restart.

Status is JSON. Connection snippets use the ready public origin for Claude Code, claude.ai, ChatGPT, Codex and Grok. The Agents page retains per-agent bearer examples and offers the OAuth Claude Code command beside the connector URL.

RMT-ONECOMMAND-FLOW runs production manager, command and HTTP probe code with an isolated fake LocalClient and listener. The fake approval opener advances login and Funnel authorization; the synthetic stream duration is shortened to one second. No real tailnet state is used. RMT-STATUS-OFF real, RMT-TS-EMBEDDED and CONN-* remain limited pending Johan authorizing an embedded node and configuring hosted connectors. Real public Ubuntu/off evidence cannot be obtained under the unattended no-login/no-Serve-change constraint.

## Public enrollment and private access (T10–T11)

`bridge web enroll --public` requires Remote on, selects the active HTTPS origin and prints its enrollment URL and terminal QR. WebAuthn RP selection continues to use the pinned serving hostname. The public-origin browser scenario uses a Chromium virtual authenticator, real product auth endpoints and isolated TLS to verify separate localhost and public credentials.

`bridge remote on --private` starts a userspace tsnet TCP listener without Funnel. Its connection code carries the tailnet host and a random invitation, valid for five minutes and consumed atomically by the Mac. Successful redemption issues a transport credential held only in memory; passkey and API authentication remain required. The connecting node uses an ephemeral in-memory tsnet identity store and reauthorizes on restart. Private approval URLs travel only over the request-scoped approval socket. `bridge connect <code>` authorizes a userspace tsnet node on the other computer and binds only `127.0.0.1:7780`. Both ends enforce `localhost:7780`, discard forwarded identity headers, and retain the localhost WebAuthn origin. Tailnet access control and passkeys remain required. This mode provides no hosted connector URL. Sim coverage exercises invitation reuse and expiry, private MCP tools/list and feed dispatch, identity storage and approval redaction with isolated node transports. The Ubuntu replica path is limited until an interactive Tailscale authorization is available.
