# Mac capture

The mac source captures audio devices, display appearance and geometry, power, network path and running applications. Grants are mac:read and mac:write; commands below mutate only the requested Mac state. Capture uses bounded notification streams, CoreAudio listeners, workspace notifications, IOPS and NWPathMonitor. Unknown device volume and mute are omitted. Night Shift is omitted. SSID is included only with existing Location authorization; capture never requests it. Time remaining is seconds when IOPS supplies an estimate. Keep-awake describes system idle-sleep assertions.

Limitations: VPN is an interface heuristic, not an authenticated tunnel health check. Real battery percentage, charging and source match pmset. Whole-Helper idle CPU remains 56.61 percent over 300 seconds after narrowing CoreAudio subscriptions. A trace sample showed 2 Mac captures versus 954 Messages and 148 Notes captures; per-source CPU is unmeasured. Assertion-only changes to keep-awake state have not been independently verified.

MCP and OpenAPI advertise operation-specific Mac arguments and ranges, without entity-version preconditions. Commands accept volume in percent (0–100), muted boolean, output device native identifier, light/dark appearance, app bundle identifier, and keep-awake on plus optional duration in seconds (at most 86400). Appearance starts System Events in the background before its no-prompt Automation check. Native readback evidence binds to the request fingerprint; no synthetic capture checkpoint is claimed. An interrupted command remains indeterminate. Keep-awake uses an owned IOPM assertion; off releases only that assertion, and duration expiry releases it. Clipboard text reads use the transient query channel. Reads and readback-qualified writes require Helper access set to Always Allow in Paste from Other Apps; denied or prompt-requiring access fails before clipboard reads or mutation. Helper status reports clipboard access, and owner-invoked onboarding can register the pasteboard access request; automated scenarios never invoke onboarding. Text writes accept at most 64 KiB, place transient and concealed NSPasteboard markers alongside text, and retain only redacted arguments and boolean readback in command history and Helper journals. Approval-required agents cannot write clipboard contents because approval would require retaining the payload. Image clipboard data remains unsupported. Real clipboard qualification snapshots up to 16 MiB of available pasteboard items and formats in memory after verifying they can be restored, writes a tagged value, checks readback and durable-file privacy, then restores the snapshot.
