# Queries

A query reads transient Helper state without world effects. Descriptor kind `query` routes REST `POST /v1/op/<name>` and MCP tools through the authenticated gateway. It uses the descriptor's read grant; read-level agents may invoke it. The descriptor registry remains per source. `helper.version` is production; `test.echo`, `test.sleep`, and `test.blob` exist only in lab builds and use `reminders:read` to exercise agent read grants. `helper.version` requires `system:read`, which remains unavailable to agent credentials. Query grant denials return HTTP 403.

Inputs contain optional `id` and `deadline_ms`, and required JSON `args`. IDs use the `qry_` prefix; omitted IDs are generated. Deadlines default to 1000 ms and cannot exceed 60 seconds. IPC uses Query, QueryResult, QueryError and QueryCancel frames. Query writes use the query context, including time waiting for the wire. Context cancellation allows 50 ms for QueryCancel and closes the session when delivery fails; peers cancel work on session loss. Native handlers must cooperate with Task cancellation and check it before returning. Query errors include `deadline`, `unsupported`, `unavailable`, and `capacity`.

Inline results are at most 1 MiB of JSON. A bounded preflight counts encoded strings, raw JSON and envelope fields before the standard encoder can allocate its serialization buffer; oversized inline JSON is rejected before serialization. Producers put larger outputs in digest-backed blobs. Larger output is represented by digest/size/handle blob references, fetched through existing BlobRead chunks and digest-checked by the blob store. Each result supports up to 16 blobs of at most 64 MiB each. A one-hour lease binds blob REST access (`?record=<query id>`) to the issuing principal and current descriptor grant; digest knowledge alone grants nothing. Expired leases are swept when another blob result arrives. Range reads use the existing blob endpoint. Revocation and grant reductions apply at the front door. Replicas delegate queries with signed principal and request hashes over the existing command channel; disconnected gateways fail fast. Validated query deadlines (up to 60 seconds) bound feed forwarding, replica exchanges and the HTTP fallback; command forwarding retains its 20-second default.

Admission limits each principal to 100 queries per second at the gateway, in addition to front-door request limits. The audit log stores operation names and separate argument, JSON result and blob byte counts; agent activity stores argument sizes; it stores no argument or result content or hashes.

Taking a photograph, recording audio, playing a sound, changing focus or any other world effect is a command. Such operations require the command approval policy and observable evidence (the artifact exists or playback finished). Labeling an operation a query never bypasses these requirements.
