# Location and Maps

Transient authenticated queries use location:read and maps:read. No query persists coordinates in State. Location current requests a single fresh fix only after existing authorization; it never requests authorization. Missing Location permission and an absent fresh fix are unavailable.

Geocoding accepts address, reverse geocoding lat/lon. Search accepts query, near (lat/lon), radius in meters; nearby substitutes category for query. Results are bounded to fifty places within the supplied radius. Distances are meters and duration values are milliseconds, following the wire contract. Directions and ETA accept from/to coordinates and mode; driving, walking and cycling use native MapKit. Transit supports ETA only; transit route geometry returns unsupported, matching the selected SDK contract.

Snapshots accept center, span in degrees and width/height (128–1024), returning a PNG blob through the query lease. Native images are preserved, with Apple Maps attribution in result metadata. Up to fifty coordinate markers and an explicit attribution label are drawn over the unmodified native image. The Helper admits eight concurrent native queries and keeps at most sixteen pending snapshots, expires their handles after two minutes, and releases each image after its final blob chunk; they are never replicated as records.

maps.open accepts a coordinate or from/to coordinates with a transport mode and verifies Maps is frontmost. Doctor source readiness reports authorization without prompting; five-minute whole-Helper idle qualification is limited by the pre-existing Messages.reconcile CPU issue tracked by T53 (54.6% on unmodified main). LOC-IDLE measured 30.49% and MAP-IDLE 38.39%, each over 300.02 seconds with the Helper responsive; neither is an idle pass. Real current location is limited: Helper Location authorization is not_determined, requiring Location Services permission for AppleBridgeHelper. Qualification uses only fixed public San Francisco landmarks; evidence contains assertion outcomes and aggregate resource metrics.
