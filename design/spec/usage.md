# Usage input fingerprints

Usage uses recursive filesystem notifications for nested local segments, remote arrivals and sync database/WAL metadata, coalescing capture checks for one second. Unrelated sync files do not wake capture; dropped-event and root-change notifications still force a check. A five-minute fallback detects missed filesystem events and time-zone changes. Power notifications also wake capture. Fingerprints retain regular file paths, sizes and modification dates, sync database and WAL metadata, power-event count and time zone. Cached stream inventories check POSIX file and directory identities, sizes, modification and change times before rebuilding the recursive URL metadata fingerprint. Sync-only changes reuse the stream inventory, and a changed capture reuses the fingerprint already computed by its wake check. Directory stamps detect additions and removals; missing sync database and WAL paths remain tracked. Append, remote arrival, sync metadata, power and time-zone changes still invalidate the fingerprint.
# Usage action probe

Biome remains the usage source. `USE-ACTION-PROBE` is a read-only real inventory check: it counts installed shortcuts and immediate local/remote Biome entries, retaining no owner shortcut names or usage values. It never runs any shortcut. The dedicated Screen Time pack is absent; action output availability and row coverage remain limited.
