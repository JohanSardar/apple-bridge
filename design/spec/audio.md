# Audio and on-device language queries

`speech.synthesize` accepts a nonempty `text` string up to 2,048 UTF-8 bytes. AVSpeechSynthesizer writes a temporary WAV without playback. The transient result contains `media_type` and a digest-backed query blob; output is bounded to 700,000 bytes. Cancellation stops synthesis and deletes the private temporary directory. Helper blob handles expire after 60 seconds and at most eight outputs are retained.

`audio.transcribe` validates inline or absolute local-file input using the shared 8 MiB document boundary. It never requests Speech authorization. It returns an unavailable status with the exact Helper authorization reason when not determined. Installed SpeechTranscriber locale assets are used with SpeechAnalyzer before considering the legacy authorization status. File analysis is limited to 120 seconds and 200,000 transcript bytes; output includes timed segments and language. No model downloads are requested. [Apple’s authorization documentation](https://developer.apple.com/documentation/speech/asking-permission-to-use-speech-recognition) distinguishes this on-device API from the SFSpeechRecognizer authorization flow. Real qualification remains pending.

`ai.local` accepts `prompt`; `ai.rewrite` accepts `text` and `style`. Both use Apple's Foundation Models framework and return `status: unavailable` with the model's reason on unsupported systems. `ai.local` optionally accepts a flat JSON object schema with string, integer, number and boolean properties and a required list; other schema forms reject. No transcripts, prompts or generated audio are recorded in lab evidence.

`speech.say` accepts text and optional volume from zero to one; `capture.play_sound` accepts an allowlisted system sound name and optional volume. Both are commands whose observed outcome requires a successful native finished callback bound to the prepared request hash. Cancellation stops playback, and recovery never replays it. Real tests use volume zero. No third-party implementation was copied. These query-only modules keep no replicated collections or polling tasks.
