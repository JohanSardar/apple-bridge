# Photos

The photos source registers photos:read and photos:write. T39 implements read-only asset and album metadata capture through public PhotoKit. Authorization is inspected with authorizationStatus(for: .readWrite); no authorization request is made. not_determined is permission_missing and never triggers a prompt. Readiness is the source doctor check.

Assets carry local_id, creation date, image/video/live/screenshot kind, duration, favorite, hidden, location and album membership. Size is null and cloud_state is unknown: public PhotoKit supplies neither without hydration. Location belongs to records only and is never printed in evidence. Album counts use fetched membership; kinds are user, smart and shared. Person and keyword are unavailable through public PhotoKit.

Limited-library access emits upserts without absence inference. Capture rechecks permission before emitting each scan, suppresses unchanged checkpoints and polls at 30 seconds. Replicas receive metadata only. photos.search accepts from/to ISO timestamps (inclusive), album local id, kind, favorite and limit (default 100, maximum 1000); truncation is explicit. Text OCR indexing remains disabled and text queries return unsupported. No OCR is scheduled. Libraries or albums exceeding 10,000 assets, or scans exceeding 100,000 memberships, fail without emitting a complete scan.

photos.original and photos.thumbnail accept an asset local id and return query-contract blobs. Originals stream PhotoKit resources with network access enabled and cancellation; thumbnails are JPEG previews requested at 256 pixels. At most two hydration requests run concurrently. Each result is capped at 16 MiB, the in-memory handle cache at 64 MiB, and handles expire after 60 seconds. Blob reads recheck authorization and current asset visibility. No blob bytes enter capture or replica storage. Real hydration remains unqualified until the Photos grant is available. PHO-CAPTURE exercises the native source using a synthetic library; PHO-IDLE proves unchanged-checkpoint suppression over five minutes with standalone CPU below 2%; whole-Helper CPU remains limited. Real capture is limited: Helper Photos readWrite authorization is not_determined and prompting is forbidden.

T40 adds photos.import (data as base64 image/video bytes, SHA-256 digest, kind image/video, optional album local id), photos.create_album (name), photos.add_to_album and photos.remove_from_album (asset and album local ids), photos.set_favorite (asset local id, favorite boolean), and photos.delete (asset local id). Imports are bounded to 16 MiB and verified against original-byte readback. Commands require photos:write; PhotoKit authorization is checked at preparation and dispatch without requesting access. Preparation validates arguments and existence; dispatch rechecks the prepared asset and album state. Album counts and membership, favorites, creation and deletion are read back after changes. Command outcomes still require the gateway's captured checkpoint before becoming locally observed.

Deletion is allowed only for assets imported by this source instance. The ownership set is intentionally memory-only: after a Helper restart an older import cannot be deleted through the bridge. Deleted assets remain in Photos Recently Deleted for 30 days. PHO-COMMANDS exercises both image and video bytes against the native fake library, digest mismatch rejection, album membership, favorite readback and rejection of external asset deletion. Real PHO-IMPORT-REAL and PHO-ORIGINAL-REAL are limited: Photos readWrite authorization is not_determined; prompt forbidden. Grant needed: Photos readWrite for dev.applebridge.helper.

Album and asset command arguments use PhotoKit local identifiers, matching photos.search and photos.original. The sim proof uses PhotosChecks with a fake library; gateway checkpoint reconciliation is wired for Photos commands but awaits end-to-end qualification with an authorized Helper. Invalid imports are rejected before PhotoKit dispatch; an error after dispatch remains indeterminate and is never retried automatically.
