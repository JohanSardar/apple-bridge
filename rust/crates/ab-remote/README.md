# Remote ingress

Relay and the installed Tailscale app implement independent `Ingress` lifecycles. Run both with `run_all`; cancel through a shared watch channel, awaiting completion so Tailscale removes its owned Serve mapping.

`state::command(home, "on", "both")` enables both. The same API accepts `on`, `off`, `status` and `relay`, `tailscale-app`, `both`. Existing `config.json`, `relay.json`, `lease.json`, SEC1 account keys and TLS keys are compatible with Go. The additive `ingresses.json` holds independent enabled flags, with config changes protected by Go's flock. Status currently returns configured selections. Product bridge CLI dispatch and gateway lifecycle reconciliation are an explicit integration request in `rust/INTERFACES.md`; this PR owns only ab-remote.

The relay uses the original signed enrollment and proof transcripts, trusted TLS WebSockets and smux v2. Public TLS terminates locally before forwarding plaintext to the runtime's loopback frontdoor. Runtime must enforce public Host/Origin policy at that listener. No replication routing policy is changed; relay/1 remains frozen and does not acquire channel binding.

Certificates reuse Go's P-256 SEC1 files. ACME uses only DNS-01, publishing and removing TXT values through signed relay requests and reporting the leaf fingerprint. Existing certificates with over thirty days remaining are reused. Renewal is serialized, replaces the certificate file atomically, and publishes a new rustls configuration for subsequent streams. The established streams retain their configuration. The normal renewal interval is twelve hours.

The Tailscale adapter uses the Unix LocalAPI, requires HTTPS and Funnel capabilities, chooses the first free allowed port among 443, 8443 and 10000, and retries ETag CAS five times. It persists Go's lease before changing Serve. Removal verifies all owned entries and preserves unrelated handlers. A random capability path protects its loopback listener; requests require exact Host and forwarded headers. Ordinary HTTP connections close after one request; WebSocket upgrades remain duplex.

Run `rust/crates/ab-remote/fixture/run.sh` on Ubuntu with Rust and Go on PATH. This builds an isolated Rust driver and drives it from an independent Go fixture against the real Go relay owner gate. All homes and listeners are temporary; no live remote config, real DNS, relay VM or Tailscale daemon is used. The synthetic ACME fixture validates the CSR and checks that a DNS value was published; it is not a full ACME conformance server. The fixture proves enrollment, gate denial, signed DNS requests, renewal, key reuse, permissions, 800 KB TLS stream delivery over Go smux v2, simultaneous adapters, CAS retry, handler preservation and graceful cleanup. The frozen relay corpus is covered by the crate's codec test.
